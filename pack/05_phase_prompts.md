# Prompts المراحل

استخدم كل Prompt في محادثة جديدة، مع إرفاق: الوثيقة الرئيسية، 01_schema.sql، 03_openapi.yaml، 04_permissions_matrix.md، وناتج المرحلة السابقة (الكود).

## قاعدة مشتركة (ضعها في أول كل Prompt)
أنت مهندس برمجيات أول. التزم حرفياً بالوثيقة والملفات المرفقة. لا تحذف ميزة ولا تغيّر اسم جدول أو عمود أو مسار أو رمز صلاحية. عند الغموض اتخذ القرار الموسوم [افتراض] ودوّنه في DECISIONS.md. كل منطق الأعمال في الخادم. اكتب اختبارات، وحدّث OpenAPI إن لزم، وأخبرني في النهاية بما نفّذته وما لم تنفّذه وسببه.

## المرحلة 1 — الأساس
نفّذ الأساس بـ ASP.NET Core 8 وEF Core على SQL Server: بنية Clean Architecture، الدخول والتجديد (القسم 3.1 و9)، الشركات والسنوات المالية، المستخدمون والأدوار والصلاحيات ونطاق البيانات حسب 04، AuditLogs التلقائي وSoft Delete وRowVersion، الإعدادات، الهيكل الإداري (شجرة وحركة وقواعد 4.1)، وكل التعريفات في 4.2. طبّق كل مسارات Auth وAdmin وDefinitions من OpenAPI. سلّم Docker Compose وبيانات تجريبية وواجهة ويب للدخول وشجرة الهيكل والتعريفات.

## المرحلة 2 — ملف الموظف
نفّذ ملف الموظف بتبويباته التسعة (4.3) وكل مساراته، «مباشرة العمل» بقاعدتها، رفع الصور والأرشيف، تشفير الحقول الحساسة، سجل الحركة من AuditLogs، وتقرير ملف الموظف بالفلاتر والعرض المتقدم والتصدير (4.4). الواجهة: صفحة ملف موظف حديثة بتبويبات حسب 11.4.

## المرحلة 3 — الحضور
نفّذ القسم 5 كاملاً: الفترات (مع المحاكي)، الربط الجماعي، الأجهزة وخدمة Agent لـ ZKTeco، الحركات الخام ومنع التكرار، العطل، الاستئذان، محرك الاحتساب اليومي كدالة نقية، الملخص الشهري والإقفال. إلزامي: اختبارات وحدة لكل صف في جدول 5.3 والحالات الطرفية المذكورة في 12 قبل أي واجهة.

## المرحلة 4 — الإجازات والطلبات
نفّذ القسم 6.1 و6.2 و7: الأنواع والأرصدة والإجازات، الطلبات ومسارات الموافقة والتفويض، الإشعارات، لوحة المعلومات والتنبيهات، والمهام المجدولة (Hangfire). تأكد أن الإجازة المعتمدة تغطي الحضور وتخصم الرصيد.

## المرحلة 5 — المالية
نفّذ 6.3 إلى 6.8: بنود الرواتب، المتغيرات، السلف والأقساط والسداد، العهد، كشف الراتب (دورة الحالة والمعادلات والمثال الرقمي)، قسيمة PDF، كشف بنكي، التأمينات، نهاية الخدمة. اكتب اختبارات للمعادلات وعكس الاعتماد.

## المرحلة 6 — الجوال
ابنِ تطبيق Flutter حسب القسم 10 فوق مسارات /mobile و/me و/requests و/notifications فقط: الدخول، البصمة بالموقع والطابور دون اتصال، السجل، الطلبات، الاعتمادات، القسائم، الإشعارات. العقد من OpenAPI ولا تغيّره.

## المرحلة 7 — التثبيت
راجع الأداء والأمان وفق القسم 12: فهارس واستعلامات بطيئة، OWASP ASVS، تشفير، نسخ احتياطي واستعادة، E2E بـ Playwright للمسارات المذكورة، وثّق README وDECISIONS.md، وسلّم تقرير تغطية الاختبارات.
