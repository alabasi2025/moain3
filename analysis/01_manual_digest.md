## أولاً: ملخص الدليل صفحة بصفحة — سطران لكل صفحة

**p-01**  
الشاشة: غلاف دليل استخدام نظام شؤون الموظفين.  
الحقول/القواعد: لا توجد حقول؛ تظهر لمحة عامة للنظام: HR، Alerts، Employees Requests، Charts.

**p-02**  
الشاشة: جدول المحتويات.  
الحقول/القواعد: يحدد أقسام الدليل: الرئيسية، الإدارة والتحكم، الهيكل الإداري، كرت الموظف، الدوام، ربط الدوام، كشف الراتب.

**p-03**  
الشاشة: تسجيل دخول المستخدم.  
الحقول/القواعد: السنة، الشركة، اسم المستخدم، كلمة المرور، اللغة، تذكري؛ الدخول يتطلب بيانات صحيحة، وزر إغلاق يلغي العملية.

**p-04**  
الشاشة: الشاشة الرئيسية للنظام.  
الحقول/القواعد: لا إدخال؛ تضم شجرة النظام، التنبيهات، طلبات الموظفين، المخططات، وشعار المؤسسة؛ يلزم تهيئة النظام والمستخدمين والسنة المالية قبل الاستخدام.

**p-05**  
الشاشة: الإدارة والتحكم.  
الحقول/القواعد: لا حقول؛ تشمل السنة المالية، الإقفالات، المستخدمين، مجموعات المستخدمين، الصلاحيات، ترويسة التقارير، التحديث، الضبط، النسخ الاحتياطي، تحويل التاريخ.

**p-06**  
الشاشة: الهيكل الإداري/التنظيمي — شرح نظري.  
الحقول/القواعد: لا حقول؛ الهيكل هرمي يوضح الإدارات والأقسام والعلاقات والمسؤوليات ومراكز التكلفة.

**p-07**  
الشاشة: الهيكل الإداري/التنظيمي — مثال هرمي.  
الحقول/القواعد: لا حقول؛ مثال جامعة: إدارة عليا ← إدارات ← أقسام، مع توضيح أهمية التسلسل الهرمي.

**p-08**  
الشاشة: إضافة الهيكل الإداري.  
الحقول/القواعد: رقم العقدة، الاسم المحلي، الاسم اللاتيني، النوع؛ الإضافة بزر + والحفظ بزر حفظ/F10 مع مراعاة التسلسل الصحيح.

**p-09**  
الشاشة: نموذج تسلسل الهيكل الإداري.  
الحقول/القواعد: رقم العقدة، الاسم المحلي، الاسم الأجنبي، النوع؛ حالة ظاهرة: تم الحفظ بنجاح، والهيكل يعرض الإدارات والأقسام.

**p-10**  
الشاشة: إعداد كرت الموظف/إدارة ملف الموظف — الحقول الأساسية المطلوبة.  
الحقول/القواعد: بيانات شخصية ووظيفية؛ بعض الحقول يجب تعريفها مسبقاً من التعريفات العامة مثل الجنسية، الديانة، الدوام، الموقع، الدرجة، الوظيفة، طبيعة العمل، نوع العقد.

**p-11**  
الشاشة: الدرجات الوظيفية والوظائف.  
الحقول/القواعد: رقم، الاسم عربي، الاسم أجنبي، ملاحظة؛ الإضافة عبر جديد ثم الاسم العربي ثم حفظ، والبحث يعرض السجلات المدخلة.

**p-12**  
الشاشة: مراكز التكلفة ومجموعات الموظفين.  
الحقول/القواعد: رقم، الاسم عربي/أجنبي، ملاحظة؛ مراكز التكلفة لتنظيم العمليات الحسابية، ومجموعات الموظفين لتجميع الوظائف المتجانسة.

**p-13**  
الشاشة: الدول والمدن + باقي التعريفات العامة.  
الحقول/القواعد: رقم الدولة، الاسم عربي/إنجليزي، المدن التابعة؛ يتم إدخال المشاريع، البنوك، الدول، التأمين، الوثائق، الكفلاء، الجنسيات، طبيعة العمل قبل إدخال الموظف.

**p-14**  
الشاشة: إدخال بيانات الموظف — البيانات الأساسية.  
الحقول/القواعد: الاسم، الهوية/البصمة، الجنسية، الديانة، الميلاد، الجوال، الموقع، الدرجة، الوظيفة، المجموعة، التكلفة، الدوام، العقد؛ الإضافة بزر جديد.

**p-15**  
الشاشة: بيانات الموظف الحكومية والمالية.  
الحقول/القواعد: الهوية، الجواز، التأمين الطبي، التأمينات الاجتماعية؛ والبيانات المالية تشمل جدول بنود المستحقات والاستقطاعات وإجمالي الراتب.

**p-16**  
الشاشة: البوابة الإلكترونية والوثائق.  
الحقول/القواعد: اسم المستخدم، كلمة المرور، نوع المستخدم، صلاحيات التطبيق؛ الوثائق تشمل نوع الوثيقة، رقمها، تواريخ الإصدار والانتهاء م/هـ.

**p-17**  
الشاشة: الأرشيف والمرافقين.  
الحقول/القواعد: الأرشيف: عنوان المرفق وملف مع استعراض/فتح؛ المرافقون: صلة القرابة، رقم الإقامة، تواريخ الإصدار والانتهاء ميلادي/هجري.

**p-18**  
الشاشة: المؤهلات والخبرات وحركة الموظف.  
الحقول/القواعد: المؤهلات: المؤهل، التخصص، تاريخ الإصدار؛ الخبرات: سنوات الخبرة، الوظيفة؛ حركة الموظف تعرض التعديلات والإضافات والتحديثات.

**p-19**  
الشاشة: تقرير ملف الموظف + عرض متقدم.  
الحقول/القواعد: فلاتر برقم الموظف، البصمة، الجنسية، الديانة، النوع، الموقع، الدرجة، المجموعة، الوظيفة، التواريخ، حالة الدوام؛ العرض المتقدم يختار أعمدة التقرير.

**p-20**  
الشاشة: معاينة تقرير ملف الموظف.  
الحقول/القواعد: تقرير عرض فقط لبيانات الموظف الشخصية والوظيفية والحكومية والمالية؛ لا إدخال ولا معادلات ظاهرة.

**p-21**  
الشاشة: إعداد فترات الدوام.  
الحقول/القواعد: رقم الفترة، العنوان، الحضور، الانصراف، ساعات/دقائق، الاستراحة، العمل الإضافي، السماح، التأخير، الخروج المبكر، دورة الدوام؛ رقم الفترة آلي وتسلسلي.

**p-22**  
الشاشة: تمهيد ربط الموظفين بفترات الدوام.  
الحقول/القواعد: قبل الربط يجب التأكد من بيانات الموظف وتنفيذ مباشرة العمل والموافقة والحفظ؛ ثم الانتقال لنظام الحضور والانصراف ← ربط الموظف بالفترة.

**p-23**  
الشاشة: إدارة فترات دوام الموظفين.  
الحقول/القواعد: اختيار الموظفين حسب الرقم الوظيفي، البصمة، الموقع، الدرجة، الوظيفة، المجموعة، مركز التكلفة، ثم اختيار فترة الدوام والضغط إنزال ثم حفظ.

**p-24**  
الشاشة: إعداد كشف الراتب — المسار والنوع.  
الحقول/القواعد: المسار نظام المرتبات والأجور ← عمليات ← إعداد كشف الراتب؛ نوع الكشف: نمطي لكل الموظفين أو مخصص حسب الهيكل الإداري.

**p-25**  
الشاشة: إعداد كشف الراتب.  
الحقول/القواعد: رقم الكشف آلي، الشهر/السنة، تاريخ الإصدار آلي، نمطي/مخصص، البيان، معاينة، اعتماد؛ المعاينة تنزل الموظفين مع المستحقات والاستقطاعات والصافي.

**p-26**  
الشاشة: تقرير كشف الراتب والعرض المتقدم.  
الحقول/القواعد: اختيار نموذج التقرير وفلاتر الراتب/القيد/الموقع/الدرجة/المجموعة/التكلفة/المشروع؛ العرض المتقدم يسمح بسحب الحقول وإظهار الإجماليات.

**p-27**  
الشاشة: معاينة تقرير كشف الراتب.  
الحقول/القواعد: تقرير عرض فقط بأعمدة رقم الموظف، الاسم، الوظيفة، الحساب، المستحقات، الاستقطاعات، الصافي؛ تظهر الإجماليات النهائية.

- شجرة النظام.
- لوحة التنبيهات Alerts.
- لوحة طلبات الموظفين Employees Requests.
- لوحة المخططات Charts.

---

- الإقفالات المالية.
- المستخدمين.

- قوالب الصلاحيات.

- تحديث النظام.

- الإعدادات المالية — ظهرت في بعض الشاشات.
- النسخة الاحتياطية.
- تحويلات التاريخ.

- السابق.
- التالي.
- مباشرة العمل.

- البوابة الإلكترونية.
- الوثائق / الهويات والوثائق.
- الأرشيف.
- المرافقين.
- الدوام الرسمي — ظهر ضمن التبويبات.

#### شاشات/أقسام داخل ملف الموظف

- التأمينات الاجتماعية.

### 5) نظام المرتبات والأجور
#### مدخلات / تعريفات مرتبطة
- تعريف بنود المستحقات والاستقطاعات — ظهر كتبويب/عنصر.
- بنود المستحقات والاستقطاعات داخل البيانات المالية للموظف.

#### العمليات
- حسابات.
- إصدار سلفة.
- استيراد الحضور السابقة.
- بدلات / استقطاعات متغيرة أو متفرقة.
- المتغيرات متغيرة / اتصالات متفرقة — ظهرت بنص غير مستقر.
- اعتماد رصيد الإجازات.
- رصيد افتتاحي للإجازات.
- إجازات الموظفين.
- إنذارات الموظفين — ظهرت في صفحة التقرير.
- عهد الموظفين.
- إخلاء عهد الموظفين.
- إعداد كشف الراتب.
- إعداد كشف الضمان الاجتماعي / التضامن الاجتماعي.
- سند نهاية الخدمة.

#### تقارير المرتبات والأجور
- تقرير السلف.
- تقرير بدلات/استقطاعات.
- تقرير الإجازات.
- تقرير عهد الموظف / الموظفين.
- تقرير كشف الراتب.
- تقرير التأمينات الاجتماعية.
- تقرير ملف الموظف.
- بيان كشف موظفين متقدم.
- تقرير كشف موظفين متقاعد — ظهر في إحدى اللقطات.

#### نماذج تقرير كشف الراتب
- تقرير كشف راتب إجمالي.
- تقرير كشف راتب تفصيلي.
- كشف راتب مع التوقيع.
- كشف راتب نقدي.
- قسيمة راتب.
- كشف راتب تفصيلي متقدم / عرض متقدم للبيانات.
