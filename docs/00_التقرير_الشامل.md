## 2. بنية النظام القائم كما يظهر في الدليل

```
نظام شؤون الموظفين (أنظمة الجزيرة)
├── الدخول: السنة المالية + رقم الشركة + المستخدم + كلمة المرور + اللغة + تذكرني (ص3)
├── الرئيسية: شجرة النظام، التنبيهات، طلبات الموظفين، المخططات (ص4)
├── الإدارة والتحكم: السنة المالية، الإقفالات، المستخدمون، مجموعاتهم، قوالب الصلاحيات،
│   ترويسة التقارير، تحديث النظام، الضبط، النسخ الاحتياطي، تحويل التاريخ (ص5)
├── التعريفات: الهيكل الإداري (شجرة: رقم العقدة/اسم محلي/لاتيني/نوع) (ص8-9)، الدرجات، الوظائف،
│   مراكز التكلفة، مجموعات الموظفين، المشاريع، البنوك، الدول والمدن، التأمين، الوثائق،
│   الكفلاء، الجنسيات، طبيعة العمل (ص11-13)
├── ملف الموظف (ص14-18) — تبويبات: أساسية، حكومية، مالية (بنود مستحقات/استقطاعات)،
│   بوابة إلكترونية، وثائق (م/هـ)، أرشيف، مرافقون، مؤهلات وخبرات، حركة الموظف
│   + زر «مباشرة العمل» شرط قبل ربط الدوام (ص22)
├── التقارير: ملف الموظف + عرض متقدم باختيار الأعمدة (ص19-20)
├── الحضور: فترات الدوام (سماح/تأخير/خروج مبكر/إضافي/دورة) (ص21)، الربط الجماعي (ص23)،
│   العطل، الاستئذان، أجهزة البصمة، المواقع، أجور المهمة
└── الرواتب: إعداد الكشف نمطي/مخصص ← معاينة ← اعتماد (ص24-25)؛ نماذج: إجمالي، تفصيلي،
    مع التوقيع، نقدي، قسيمة (ص26-27)؛ سلف، متغيرات، إجازات، عهد، تأمينات، نهاية خدمة، إنذارات
```

الحزمة الجديدة تغطي هذا كله تقريباً بـ **81 جدولاً، 194 مفتاحاً أجنبياً، 173 مساراً/319 عملية، 248 صلاحية، 7 أدوار** — وتضيف ما ليس في القديم: مسارات موافقات وتفويض، بصمة جوال بالموقع وطابور دون اتصال، إقفال شهري للحضور، سجل تدقيق شامل، عروض تقارير محفوظة.

## 8. أسئلة يجب أن يجيب عنها صاحب النظام قبل البدء

1. **أرسلوا «الوثيقة الرئيسية»** (مواصفات بناء HRMS، الأقسام 3-13) — أهم عائق.
2. هل المنشأة مشمولة بالتأمينات الاجتماعية؟ (يحدد معادلة نهاية الخدمة: م120/1 مقابل م120/2) وما النسب السارية فعلاً؟
3. ما معنى «سجل الاستنادات» في كشف الراتب، و«لا يحتسب ساعات العمل» في الفترة، و«اللغة» في ملف الموظف؟
4. هل الربط بالدوام قبل «مباشرة العمل» ممنوع منعاً أم تنبيه فقط؟
5. هل الكشف «المخصص» لموظف واحد أم لعقدة من الهيكل؟ (`PayrollRuns.ScopeJson`)
6. هل يلزم دوام رمضاني آلي وبدل ليلي/نوبات؟
7. هل المطلوب وحدة جزاءات كاملة (تحقيق، تظلّم، سقوط) أم سجل إنذارات فقط؟
8. هل مطلوب ربط محاسبي (قيود رواتب) في هذه المرحلة؟
