# مواصفة بديلة [مستنتج] — محرك الحضور اليومي وكشف الراتب

> **تنبيه:** هذه مواصفة بديلة مؤقتة لأن «الوثيقة الرئيسية» (الأقسام 5.3 و6.x) غير مرفقة. مستنتجة من أعمدة المخطط وقيوده ومسارات API والدليل وقانون العمل اليمني. عند وصول الوثيقة الأصلية **تُقدَّم عليها**.
> المصدر التفصيلي: `analysis/agents/D_arch.md` (23 حالة) — مع التصحيحات أدناه.

## 1. محرك الحضور اليومي — دالة نقية

```
Compute(shift: Shifts+ShiftDays, punches: PunchLogs[accepted], holiday?: OfficialHolidays,
        leave?: Leaves[approved], excuses: Excuses[IsApproved=1], settings) -> DailyAttendance
```
لا وصول لقاعدة البيانات ولا للساعة داخل الدالة؛ `POST /shifts/simulate` و`POST /attendance/process` يستدعيانها.

### ترتيب الأسبقية (حتمي)
1. `Leaves` معتمدة تغطي اليوم ⇒ `Status=leave`، `RequiredMinutes=0` (نصف يوم: Required/2) — [افتراض]
2. عطلة رسمية: بلا بصمات ⇒ `holiday`؛ مع بصمات ⇒ `holiday_work` وكل الدقائق إضافي بمعدل 2× (م56/ب)
3. `ShiftDays.IsWorkDay=0`: بلا بصمات ⇒ `weekend`؛ مع بصمات ⇒ `present`، `RequiredMinutes=0`، الدقائق إضافي 2× (م56/ب: يوم الراحة)
4. يوم عمل: تُطبّق النوافذ `BeforeInMin/AfterInMin/BeforeOutMin/AfterOutMin` لاختيار أول دخول وآخر خروج؛ البصمات خارج النوافذ تُهمل؛ المكررة داخل دقيقة تُدمج.

### المعادلات (يوم عمل)
```
Required   = Shifts.WorkMinutes            (رمضان: min(WorkMinutes, 360) — م71/2)
LateRaw    = max(0, In  - Start)
LateMin    = LateGraceEnabled ? (LateRaw <= LateGraceMin ? 0 : (LateAfterGrace ? LateRaw - LateGraceMin : LateRaw)) : LateRaw
EarlyRaw   = max(0, End - Out)
EarlyLeaveMin = نفس منطق Early*  (EarlyBeforeGrace)
ExcusedMin = تقاطع فترات الاستئذان المعتمدة مع [Start, End] ثم تُطرح من Late/Early المتقاطعة معها
WorkMinutes= min(Out,End) - max(In,Start) - BreakMinutes   (≥0)
AbsentMin  = max(0, Required - WorkMinutes - ExcusedMin) - LateMin - EarlyLeaveMin  (≥0)
OvertimeMin= OvertimeEnabled ? دقائق العمل داخل [OvertimeFrom, OvertimeTo] خارج الدوام : 0
             مع سقف: WorkMinutes + OvertimeMin <= 720 (م74/2)
Status     = لا بصمات ⇒ absent ؛ بصمة واحدة ⇒ (PresentIfNoOut/PresentIfNoIn ? present : absent) ؛ غير ذلك present
             إن غطّى الاستئذان كامل النقص ⇒ excused
```
الفترة الليلية (`CrossesMidnight=1`): `WorkDate` = تاريخ بداية الفترة، و`End` = اليوم التالي.

## 2. دورة حالة كشف الراتب (من `CK_PayrollRuns_Status` والمسارات)

```
draft ──calculate──▶ draft(محسوب) ──(review)──▶ approved ──pay──▶ paid
                                        ▲            │
                                        └─unapprove──┘  (يعكس أقساط السلف؛ ممنوع بعد paid)
```
- `calculate` مسموح في `draft` فقط؛ يتطلب إقفال `MonthlyAttendances` للشهر [افتراض].
- `approve`: يقفل الكشف ويرحّل `AdvanceInstallments.Status=deducted` ويعلّم `VariableItems.IsApplied=1`.
- الحذف (`finance.payroll_runs.delete`) للمسودة فقط.
- القسيمة/الكشف يجب أن يتضمن التفاصيل والاستقطاعات والصافي وأن يُوقَّع (م66).

## 3. المعادلات + مثال رقمي مُصحَّح (ريال يمني)

```
DayRate      = Basic / 30                         (م9: الشهر 30 يوماً)
HourRate     = DayRate / DailyHours
Absence      = AbsentDays × DayRate               (+ AbsentMin غير المكتملة × HourRate/60)
Late         = (LateMin + EarlyLeaveMin)/60 × HourRate
Overtime     = OTnormal/60 × HourRate × 1.5  +  OTnight_rest_holiday/60 × HourRate × 2.0   (م56 — من الأساسي)
InsurableWage= Σ بنود SubjectToInsurance=1
InsEmployee  = InsurableWage × 6%  ؛  InsEmployer = InsurableWage × 9%   (ق26/1991 — يظهر في كشف التأمينات لا في صافي الموظف)
Installment  = AdvanceInstallments(period).Amount
Net          = Σ earnings − Σ deductions
```

**المثال:** أساسي 300,000؛ `DailyHours=8`؛ غياب يوم؛ تأخير 60 د؛ إضافي عادي 120 د؛ قسط سلفة 20,000.

| البند | الحساب | المبلغ |
|---|---|---|
| الأجر اليومي | 300,000 ÷ 30 | 10,000 |
| أجر الساعة | 10,000 ÷ 8 | 1,250 |
| الأساسي | | 300,000 |
| الإضافي | 2 × 1,250 × 1.5 | **3,750** (لا 5,625 كما ورد في مخرج الوكيل) |
| **إجمالي المستحقات** | | **303,750** |
| خصم غياب | 1 × 10,000 | 10,000 |
| خصم تأخير | 1 × 1,250 | 1,250 |
| تأمينات (الموظف 6%) | 300,000 × 6% | 18,000 |
| قسط سلفة | | 20,000 |
| **إجمالي الاستقطاعات** | | **49,250** |
| **الصافي** | 303,750 − 49,250 | **254,500** |
| حصة صاحب العمل (كشف التأمينات) | 300,000 × 9% | 27,000 |

## 4. نهاية الخدمة
- مؤمَّن عليه: المعاش/المكافأة من التأمينات (م120/1)؛ النظام يحسب فقط الأجر المستحق حتى آخر يوم + بدل الإشعار إن لم يُشعَر (م38).
- غير مؤمَّن عليه: `Gratuity = آخر أجر شهري × سنوات الخدمة` بحد أدنى شهر/سنة (م120/2)، ولا يجوز إسقاط أي جزء منها (م120/3).
- رصيد الإجازة عند الانتهاء `LeaveCashAmount` [افتراض]: م79/6 تمنع التنازل النقدي أثناء الخدمة؛ صرف الرصيد عند الانتهاء ممارسة شائعة لكنه **غير منصوص** — قرار للعميل.
- بعد الاعتماد: وثيقة إنهاء خدمة مجانية فيها تاريخ الالتحاق والانتهاء ونوع العمل والأجر (م41).
